# Skill Farmer's Toolkit (ClaudeFarm)

Build reliable Claude skills fast, then prove they work before you ship.

## Tools

```
node scripts/scaffold.js "invoice parser"   # generate a valid skill
node scripts/lint-skill.js ./some-skill      # validate before shipping
```

Both run against sensible defaults with no arguments.

## Requirements

- Node.js 18+ (standard library only).
